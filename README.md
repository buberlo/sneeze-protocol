# Sneeze Protocol

> A turn-based office game where holding a sneeze creates worse problems.

Players move through meeting rooms, elevators, and conference tables while managing sneeze pressure and available noise masks. Timing a sneeze incorrectly starts cough chains, alerts coworkers, and changes the room’s etiquette rules. The weird core loop is that suppressed sneezes split into smaller sneezes, forcing risk management.

## Features
- Turn-based sneeze timing with risk meters for cough and eye rolls
- Mask and throat inventory that changes room etiquette
- Cough chains spread to coworkers and create side quests
- Room-specific rules for conferences, elevators, and break rooms

## Stack
- Godot
- GDScript
- SQLite

## Getting started
```
Install Godot 4.x, open the project in the Godot editor, and press F5 to run; SQLite is used for save data and can be initialized on first launch.
```
